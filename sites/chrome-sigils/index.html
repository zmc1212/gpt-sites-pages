✦ 符记 SIGILS
手绘一笔,即成 chrome 金属符记。在玻璃面上随手勾勒曲线, 它们立刻膨胀为镜面镀铬的立体形状——Y2K 时代的铬金属符号美学。 五种材质、三套光影环境、左右对称模式,随手就能出一枚又冷又亮的金属符。
左键 / 单指 画笔 · 右键 / 双指 旋转视角 · 滚轮缩放 · 点笔画选中 · R 随机符记 · S 存图
题材复刻自 cl0nazepamm/sigils(MIT), 经 threejs.cc 开源专题收录;本站为原创简化实现,几何 / 环境贴图 / UI 全部程序化生成。
操作说明
左键拖动 / 触屏单指画笔画(首尾相接自动闭合成环)
右键 / 中键拖动 · 触屏双指旋转视角(双指捏合缩放)
滚轮缩放
点一下笔画 / Tab选中笔画,可改宽、加镜像、删除
Ctrl/⌘+Z · Ctrl/⌘+Shift+Z · Ctrl/⌘+Y撤销 · 重做
1–5材质:镀铬 / 18K 金 / 玫瑰金 / 黑釉 / 幻彩
Q / W / E环境:影棚 / 霓虹 / 落日
R · X · S · Del · H随机符记 · 对称开关 · 保存 PNG · 删除选中 · 本说明
小技巧:笔画越舒展,铬面反射越好看;把「笔画粗细」调大可以画充气气球字。
